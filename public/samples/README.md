# Audio Samples for Deepfake Voice Detector

This folder contains standard audio samples used by the "Try a sample" chips in the interactive dashboard:

- `real_sample.wav`: Authentic speech recording example (clean formants, natural human pitch harmonics).
- `fake_sample.wav`: Synthesized speech example (TTS/voice-cloned artifacts, unnatural modulation).

You can drop your own `.wav` recordings here or replace these files with real audio recordings from the ASVspoof 2019 dataset if desired.
