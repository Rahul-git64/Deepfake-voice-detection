# Out-of-Domain Real Audio Directory

Please place 20+ recordings of genuine human voices here (e.g. phone recordings, voice memos, microphone captures in .wav, .flac, or .mp3 format).

If this directory remains empty when running Benchmark Test 7 (Out-of-Domain Generators), the benchmark will automatically fall back to using 40 bona fide clips sampled from the ASVspoof 2019 dev set, clearly flagging them as in-domain baseline controls in the final report.
